# Ужин наугад

Исходник компонента на React Native для платформы, где он уже крутится (`platform-hooks`, навигация, камера). Это не отдельное веб-приложение: файл `dinner-spin.js` нужно вставить обратно в тот же компонент вместо прежней версии.

В `dinner-spin.js` лежит компонент для платформы: свайп удаления держит палец до отпускания, кнопка «Удалить» с теми же скруглениями, что у карточки, фото заведения выбираются в галерее и сразу попадают в форму, лимит бюджета растёт вместе с ценой блюда.
