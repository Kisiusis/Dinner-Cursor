# Ужин наугад

Исходник компонента на React Native для платформы, где он уже крутится (`platform-hooks`, навигация, камера). Это не отдельное веб-приложение: файл `dinner-spin.js` нужно вставить обратно в тот же компонент вместо прежней версии.

В `dinner-spin.js` лежит компонент для платформы: заведение открывается отдельным экраном, фото заведения выбирается в той же галерее, что и фото рецепта, на вкладке рецептов поиск — обычная строка, а фильтры можно сбросить.
