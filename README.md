# Ужин наугад

Исходник компонента на React Native для платформы, где он уже крутится (`platform-hooks`, навигация, камера). Это не отдельное веб-приложение: файл `dinner-spin.js` нужно вставить обратно в тот же компонент вместо прежней версии.

В `dinner-spin.js` лежит компонент для платформы: блюда — это домашние рецепты с ценой и временем готовки, кнопка «Извне» открывает каталог или один zip с блюдами и заведениями вместе с фото, а случайный выбор смешивает их по фильтру.
