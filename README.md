# Ужин наугад

Исходник компонента на React Native для платформы, где он уже крутится (`platform-hooks`, навигация, камера). Это не отдельное веб-приложение: файл `dinner-spin.js` нужно вставить обратно в тот же компонент вместо прежней версии.

В `dinner-spin.js` лежит компонент для платформы: поиск и свайп в шестерёнке (свайп закрывается при прокрутке и обратном жесте), выбор до 10 фото заведения с кнопкой «Использовать», русские «Переснять» и «Использовать» после съёмки, и лимит бюджета, который растёт вместе с ценой блюда.
